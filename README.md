# Neural Networks

This repository presents the core theoretical principles of neural networks and connects them with concise, dependency‑minimal code implementations. The objective is to build intuition from first principles and illustrate how standard neural network components work under the hood.

## Structure

- **Theory notes** — clear explanations of key concepts such as perceptrons, activation functions, gradient descent, backpropagation, and network architectures.
- **Code implementations** — small, standalone Python scripts that reproduce central ideas without relying on heavy deep learning frameworks.
- **Exercises and experiments** — short demonstrations to verify understanding and show how theoretical ideas behave in practice.

## Reference

The content is primarily inspired by:


> Nielsen, M. A. (2015). *Neural Networks and Deep Learning*. Determination Press.

This book provides one of the most accessible introductions to the mathematics and mechanics behind neural networks and serves as the main theoretical foundation for the repository.
